# Learning Lab

`learning_lab/`仅用于模型评测与RAG系统评测的学习、概念验证和最小复现实验，不属于当前正式Pipeline或冻结基线。

## 隔离规则

- 实验不得修改、覆盖或重新生成现有冻结数据、Manifest和正式评测结果。
- 实验所需的输入、配置、脚本、缓存、输出和说明应保存在`learning_lab/`内部。
- 实验不得依赖向正式项目目录写入文件；失败、异常退出或清理实验时不应影响主项目。
- 使用冻结资产作为只读输入前，必须确认不会向其原路径写回。
- 每个实验使用独立目录、明确名称和可区分的版本或`run_id`，避免与正式资产混淆。

## 结论边界

- 学习实验结果只用于形成理解、验证假设和支持后续Demo设计。
- 未经人工审核和明确决策，学习结果不得自动写入`README.md`、`PROJECT_STATE.md`、`DECISIONS.md`或正式项目结论。
- 实验结果不能自动改变当前Retriever选型、Judge Rubric、Benchmark标签或医学安全结论。
