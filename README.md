# Knee RAG Evaluation

基于临床指南的膝痛与膝骨关节炎 RAG 问答及医学安全评测 Demo。

## 项目目标

本项目面向成人膝痛及膝骨关节炎患者咨询场景，搭建指南驱动的 RAG 问答原型，并从以下三个层面进行评价：

1. 检索质量；
2. 证据忠实性；
3. 临床安全性。

项目将比较无 RAG 与 RAG 回答，分析错误来自检索、生成还是医学适用性，并通过固定评测集进行优化回归。
